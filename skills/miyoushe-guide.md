# 米哈游游戏攻略查询

用户问**原神 / 星穹铁道 / 崩坏3 / 绝区零 / 未定事件簿**等米哈游游戏的攻略、角色配装、武器圣遗物（遗器/光锥）推荐、活动公告、培养材料时——**优先走米游社工具**，不要上来就联网搜索。

## 标准流程（米游社优先）

1. **先 `miyoushe_search`**：用「角色名 / 主题 + 攻略/配装/圣遗物」做关键词，`game` 选对应游戏（原神 / 星穹铁道 / 崩坏3 / 绝区零）。从结果里挑**最相关的 1-2 个帖子**（看标题、互动数、`精华/官方` 标）。
2. **再 `miyoushe_post`**：用挑中的 `postId` 取详情。
   - **该工具会把帖子里所有图片自动发到聊天**（攻略多是图集，配装/圣遗物/技能加点常以图为主）。
   - 你**只需转述正文要点 + 总结结论**，不用自己描述图片内容、也不要再贴一遍图片 URL。
   - 图集帖放心调，图会全部发出来（不会只发一张）。
3. 想补充玩家讨论 / 具体问题，可再调 `miyoushe_replies` 看热评。

## 什么时候才用联网搜索（web_search）

仅当下列情况才 `web_search`，且优先中文来源：
- 米游社搜索**没有相关帖子**，或结果都不相关；
- 用户**明确要非米哈游来源**（B 站测评、外网 wiki、第三方工具如 genshin.honeyhunter）；
- 涉及**版本前瞻 / 未上线内容**（米游社可能还没有帖子）。

## 约束

- **不要**米游社还没搜就直接联网——米哈游游戏内容米游社最全最准（官方社区）。
- **不要**让用户自己点链接看图——`miyoushe_post` 已自动发图，你转述文字即可。
- 帖子图多时放心用 `miyoushe_post`，所有图都会发到聊天。
- 搜不到就如实说搜不到，再问用户要不要联网兜底，别编造攻略。
